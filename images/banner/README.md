# Ana sayfa banner görselleri

- `01-banner.webp` – `06-banner.webp`: bilgisayar için 1920 × 720 yatay görseller.
- `01-mobil.webp` – `06-mobil.webp`: telefon için dikey afişler.
- Aynı dosya adlarıyla yeni görsel yükleyerek mevcut bannerı değiştirebilirsiniz.
- Yeni slayt eklemek için index.html içindeki hero-banner-track alanına bir figure/picture bloğu daha ekleyin.
- Otomatik geçiş süresi index.html içindeki data-interval-seconds="5" alanından saniye olarak ayarlanır.
